Step 1 — Save the backup file

Downloads everything in this browser as one JSON file. Keep it on a flash disk or Google Drive. It includes the PINs.


  


  

    
Step 2 — Bring the data back into the POS app

    
    
      
  1. Make sure this computer is online, then open the POS app from the same address and hard-refresh once (Ctrl+Shift+R) so the latest app loads.
    2. 
      
  2. The new app puts all old data into "Old data archive" and starts fresh. Log in as Optimas Admin, PIN 0735 (or Cashier, PIN 2323).
    3. 
      
  3. Go to Settings → Backup and click Restore from file — choose the backup file you downloaded above.
    4. 
      
  4. Log back in with the old PIN from the file, or the new one if you were asked to change it.
    5. 
      
  5. While the app is signed in and online it now pushes everything up to the shop server automatically (Settings → Sync shows the counts).
    6. 
      
  6. Repeat the same backup file on any other computer's app to give it the identical data.
    7. 
    

  


  

    Important: never clear this browser's history or site data before saving the backup above —
    clearing site data deletes the local database for good. And never click "Restore" on a device whose
    data you don't have a backup of.
