This page works without logging in. It reads the data stored in this computer's browser (products, sales, staff PINs, customers...) and either downloads it as a backup file or pushes it to your central server.

Step 1 — Save a backup file

Downloads everything in this browser as a JSON file. Keep it on a flash disk or Google Drive. This file can be restored later from the app's Settings → Restore from file.

Step 2 — Push products & sales to the central server

Sends the products, sales and staff PINs from this browser into the Proxmox server's database. Safe to click more than once — repeated pushes update the same entries.

The server address is the one your browser POS connects to, plus /api — e.g. http://192.168.1.50:8787/api.
